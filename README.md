# Pinball Game

This game is a fun and engaging mimic of the classic pinball game, built using HTML, CSS, and JavaScript. It challenges players to control the ball and hit targets to score points. The game features smooth animations, realistic physics, and an interactive user interface, making it both entertaining and visually appealing. 

---

## Features
- **Interactive Gameplay:** Use arrow keys or the on-screen buttons to control the paddles.
- **Score Tracking:** Displays the current score and high score during gameplay.
- **Responsive Design:** Scales the game interface based on screen size.
- **Physics-Based Movement:** Realistic ball and paddle dynamics using Matter.js.

---

## Technologies Used
- **HTML5**: Structure of the game.
- **CSS3**: Styling and responsiveness.
- **JavaScript**: Game logic and interactivity.
- **Matter.js**: Physics engine for realistic game physics.
